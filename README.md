# KU_HSPC_2026
This is my entry to the 2026 KU High School Design Contest.

Gunter needs a website! Luckily, we have one for him. It has accounts, a wait-list, and even a game to play while his customers wait for their orders to be finished! The best part is that it's easy to deploy. This project was written mostly in PHP, with very little JavaScript and CSS code to improve user experience. This is my first time writing a project from the ground up with PHP, so it was a very fun experience.

# INSTALLATION
## Debian:
Install the following packages:
``mariadb-server
mariadb-client
apache2
libapache2-mod-php
php
php-db
php-mysql``

Run `install.sh` as root.
Change `$databasePassword` variable in `www/html/config.php`
